# THE UNDERLEAF — Beneath the Great Canopy

Poster wisata vintage untuk **THE UNDERLEAF**, kota di dalam batang pohon
raksasa berlubang — jendela-jendela bioluminesen hijau-emas menyala di balik
kulit kayu, di bawah kanopi agung. Tempat ini tidak ada; poster ini mengajakmu
ke sana.

## Cara kerja

`main.py` (Python + Pillow) menggambar poster 1024×1024 dan menulis
`/output/entry.png`:

```sh
python3 main.py
```

Satu-satunya teks di gambar adalah nama tempat, **THE UNDERLEAF**, digambar
dengan Playfair Display 900 (dibundel di `assets/`). Landmark: batang pohon
raksasa berlubang berisi kota bercahaya; komposisi mengantar mata dari nama,
ke landmark, ke horizon kabut di dasar hutan.
